# ENLARA — Red de negocios locales

MVP estático listo para GitHub Pages. Reemplaza RED1/MASHI.
Incluye landing, formulario de registro, catálogo demo, FAQ y estructura preparada
para conectar Firebase.

## Publicar
1. Sube todo el contenido de `public/` a tu repositorio GitHub Pages, o mueve estos archivos a la raíz.
2. Activa Settings > Pages > Deploy from branch.
3. Cambia los datos de contacto en `public/app.js`.

## Importante
Este paquete es un MVP frontend. Para producción todavía debes conectar:
- Firebase Authentication
- Firestore
- reglas de seguridad
- panel privado de negocios
- generación/validación de QR
- sistema de beneficios y métricas
